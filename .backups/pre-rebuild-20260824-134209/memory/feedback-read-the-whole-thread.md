Read every message in the ticket you're drafting on, oldest first, however long it is. If the tool output is too large, dump all messages to a file and read them there. Never print "the last N messages."

**Why:** Atira, 2026-08-22: *"Theresa why didn't you read her earlier message isn't that a requirement."* It is. On a 12-message thread I read only the last five to save context and drafted a stair-wheel technique that contradicted the answer Atira had sent the same customer four days earlier. I also missed a free-shipping promise and a restock date we'd already quoted her. All three were in the messages I skipped.

**How to apply:** The cheap subjects-only scan applies to *other* tickets, never to the thread being answered. Before drafting, be able to answer: what have we already told this person, and am I about to disagree with it? See [[feedback-follow-skill-steps]], [[strolee-wheel-positions]].
