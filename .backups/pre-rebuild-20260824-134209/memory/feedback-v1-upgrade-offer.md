Always mention the V2 upgrade program ($40 off) when responding to V1 Stability Shopper customers who run into compatibility issues (wrong wheels, missing features, etc.).

**Why:** Atira corrected this on 2026-08-18. These situations are a natural opportunity to offer the upgrade, since the customer is already interested in V2-only accessories. It's not a hard sell, it's a helpful option alongside the return.

**How to apply:** Any time a V1 customer contacts us about V2-only accessories, returns due to version mismatch, or asks about features only on V2, include the upgrade offer as an option. Link the V2 product page. Don't create the discount code until the customer confirms interest. See [[strolee-product-facts]] for upgrade details.
