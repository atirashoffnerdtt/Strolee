Gorgias tickets from `...@chat-seller-us.tiktok.com` ("TikTok Shop Seller Assistant", subject "A new message from TikTok Shop customer [handle]") are notification copies. Recommend closing them. Never draft a reply.

**Why:** Atira, 2026-08-22: *"We don't need to answer messages like 288940551, those need answered in tiktok so you can recommend to close them."* The real conversation lives in TikTok Shop and is answered there, so an emailed reply is work nobody uses. Holds even when the message is a genuine product question or a creator/affiliate ask.

**How to apply:** The relay sender address is the only thing that makes it bucket A. Someone emailing connect@stroleecarts.com from their own address about TikTok, a TikTok sample, or a collab is a normal ticket and still gets a real reply. See [[strolee-collabs-affiliate]].
