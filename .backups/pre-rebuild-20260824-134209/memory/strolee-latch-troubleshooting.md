## Cart (Stability Shopper) — "Clipping Open" macro
1. Fully release the button on the handle
2. Push the handle down and back slightly to ensure it fully clips in the open position — a quick swift "snap" motion helps
3. Try it with the shopping bag removed so you can see the latching mechanism easier
4. The small piece needs to go inside of the larger piece to ensure it clips open
- There is a reference photo in the Gorgias macro (id: 220545) showing the latching mechanism in a red box

## Baby Stroller (Single/Baby+) — "Single Baby Clipping Open" macro
1. Fully release the button on the handle
2. Push the handle down and back slightly — a quick swift "snap" motion helps ensure it clips open
3. When the stroller is extending, make sure you are NOT just letting the front wheels smack into the ground
4. If the stroller is open but not clipped in place, place your thumb on top of the handle and pointer finger behind the handle where it goes down toward the seat, and clip it open that way

## Important
- Always troubleshoot BEFORE offering a return
- Ask for a photo of the latching mechanism if troubleshooting doesn't resolve it
- Never affirm that the product is unsafe or defective. See [[strolee-never-affirm-defects]]
