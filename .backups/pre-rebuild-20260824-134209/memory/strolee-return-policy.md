## Return Requirements
- Item must be in **original packaging with product tags**
- Item must have **only been tested indoors**
- **Shipping both ways is deducted from the refund** — the cost of shipping to the customer AND the return shipping back to Strolee are both deducted from the eligible refund amount
- Refund processed within **5 business days** of receiving the item back
- Customer drops off at **FedEx** with the return label

## Process
1. **Troubleshoot first** if the return is about a product issue (latch, wheels, etc.)
2. Confirm customer has original packaging, product tags, and only tested indoors
3. Mention shipping is non-refundable and state the eligible refund amount (leave blank for Atira to fill in if unknown)
4. Once confirmed, process return and send return label via email
5. Customer attaches label to outside of box and drops at FedEx

## Tone (from Atira corrections 2026-08-17)
- Don't be aggressive about requirements. Say "to be eligible for a return" not "you must"
- Don't say "can you please confirm all of that" — instead say "if you can confirm all of that, just let me know and I can get a return label sent over to you"
- Show empathy — "I'm sorry you didn't get to use it for your trip" etc.
- If multiple items, make clear ALL items need to be returned together

## Store Credit Alternative
- Can offer store credit for the item value instead of a return (saves return shipping hassle for both sides)
- Use when trying to be cost-effective, e.g. loyal customer bought wrong item
