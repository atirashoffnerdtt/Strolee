I never send a reply, apply a macro, close a ticket, or post an internal note in Gorgias. I type the draft reply out in the chat for Atira to review, and she sends it herself.

**Why:** Atira reviews every customer-facing message before it goes out. Stated 2026-08-15.

**How to apply:** Gorgias tools are read-only in practice — reading tickets, customers, macros, help center articles, and reporting is fine. Any write or send tool (`create_message`, `reply_and_close`, `apply_macro`, `add_internal_note`, `update_ticket`, etc.) stays untouched unless Atira explicitly asks in that moment. Output drafts as plain text in chat. Also: the internal-notes feature is not used at all. Wording rules in [[gorgias-reply-tone]].
