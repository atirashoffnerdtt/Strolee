Every time you learn something new during a ticket session, save it to memory right away. This includes new links, response patterns, problem types, product facts, troubleshooting steps, and policy clarifications.

**Why:** The whole point of memory is to get faster at answering tickets over time. If you keep re-learning the same things or asking Atira for the same links, it wastes her time and slows everything down.

**How to apply:** After any correction, new link, new product fact, or new response approach comes up in a session, save it to the appropriate memory file before moving on. Check if an existing memory file should be updated rather than creating a new one. See [[feedback-do-the-legwork]], [[feedback-minimize-tickets]].
